#### 📱 Funcionalidades Principais:

**✅ Seleção de Mockup Liso**
- 3 opções de mockup base:
  - Camiseta Básica Lisa - R$ 89,90
  - Moletom Liso - R$ 179,90
  - Polo Lisa - R$ 129,90

**✅ Upload de Arte (Frente e Verso)**
- Upload separado para frente e verso
- Suporta PNG, JPG e SVG
- Preview em tempo real

**✅ Visualização Frente/Verso**
- Botões de alternância FRENTE / VERSO
- Indicador visual (✓) quando há arte aplicada
- Preview instantâneo ao alternar
- Mockup diferente para cada lado

**✅ Controles Independentes**
- Tamanho da arte (50% - 150%) para frente
- Tamanho da arte (50% - 150%) para verso
- Rotação (0° - 360°) para frente
- Rotação (0° - 360°) para verso
- Remoção individual de cada arte

**✅ Personalização do Tecido**
- 5 cores disponíveis:
  - Preto (#000000)
  - Branco (#ffffff)
  - Cinza (#808080)
  - Azul Marinho (#001f3f)
  - Verde Musgo (#4a5d23)

**✅ Configuração do Pedido**
- Seleção de tamanho (PP ao XXG)
- Quantidade ajustável
- Cálculo automático do total
- Botão de adicionar ao carrinho

**✅ Recursos Adicionais**
- Download do mockup em alta resolução
- Validação: só permite adicionar ao carrinho com arte na frente
- Integração completa com carrinho de compras

## 🎨 INTERFACE DO USUÁRIO

### Layout em 2 Colunas:

**COLUNA ESQUERDA (Preview)**
1. Botões FRENTE / VERSO
2. Preview do mockup com arte aplicada
3. Controles de tamanho e rotação (dinâmicos)
4. Botão de remover arte
5. Botão de download

**COLUNA DIREITA (Configuração)**
1. Seleção do modelo de mockup
2. Upload de arte (frente e verso)
3. Seleção de cor do tecido
4. Tamanho e quantidade
5. Resumo do pedido
6. Adicionar ao carrinho

---

## 📊 FLUXO DO CLIENTE

1. **Escolher Mockup** → Cliente seleciona camiseta, moletom ou polo
2. **Upload Frente** → Cliente faz upload da arte para frente
3. **Upload Verso** (opcional) → Cliente faz upload da arte para verso
4. **Ajustar Arte** → Cliente ajusta tamanho e rotação em cada lado
5. **Visualizar** → Cliente alterna entre frente e verso para ver resultado
6. **Escolher Cor** → Cliente seleciona cor do tecido
7. **Configurar Pedido** → Cliente escolhe tamanho e quantidade
8. **Adicionar ao Carrinho** → Arte é salva com todas as configurações

---

## 🔧 INTEGRAÇÃO COM CARRINHO

Quando o cliente adiciona ao carrinho, são salvos:
- Mockup selecionado
- Arte da frente (imagem + escala + rotação)
- Arte do verso (imagem + escala + rotação)
- Cor do tecido selecionada
- Tamanho escolhido
- Quantidade
- Preço total calculado
